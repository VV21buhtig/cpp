# webgpuelectronsdh_engine — SDF-движок на WebGPU + Electron

> Поправка терминов: **SDH не существует**. Правильно — **SDF** (Signed Distance
> Field): геометрия задаётся кодом `f(p) = расстояние до поверхности`, рендер —
> sphere tracing луча. Это и есть «геометрия через код».

## Что это
Второй движок рядом с воксельным: вместо мешей/вокселей — процедурные SDF-сцены
(шар + бокс + melt + дырка + земля), рендер одним фулскрин WGSL-шейдером:
sphere tracing (100 шагов), нормаль из градиента, солнце + мягкие тени + небо
(приближено к палитре vulcan: `sunCol/ambSky/ambGnd`), туман. Камера — орбит
мышью + зум колесом.

## Запуск
```sh
cd webgpuelectronsdh_engine
npm install          # electron + typescript
npm start            # tsc + electron .
# или без Electron, просто в браузере:
npx serve . -l 3000  # Chrome/Edge 113+, открыть http://localhost:3000
```

## Раскладка
- `src/main.ts` — Electron shell (окно 1280x720, без меню).
- `renderer.js` — WebGPU init, пайплайн, UBO камеры (64Б), рендер-луп.
- `index.html` — canvas + подключение.
- Сцена правится в `map()` внутри `renderer.js` (примитивы `sdSphere/sdBox/sdPlane`,
  комбинаторы `opU/opS/smin`).

## Честные замечания (про C и Electron)
1. **Ядра на C здесь нет и пока не надо.** WebGPU в Electron = тот же Chromium/Dawn,
   движок полностью на TS+WGSL. C имеет смысл позже и только точечно: нативный
   аддон (N-API) под тяжёлую CPU-логику или port SDF-ядра. Не тащить C ради галочки.
2. **Electron нужен только для десктопной оболочки** (окно, меню, файлы). Сам
   движок работает в любом браузере — проверяй там, это быстрее.
3. **SDF ≠ замена вокселям.** Это другой инструмент: бесконечная точность,
   CSG-булевы и фракталы даром; цена — стоимость реймарша растёт со сложностью
   сцены (считай шаги в `map()`). Для мира уровня vulcan (100k+ квадов) SDF в лоб
   не годится — держи сцены компактными или переходи на SDFGI/гибрид позже.
4. Следующие шаги: WASD-fly камера, TAA-аккумуляция истории (как в vulcan!),
   sky-LUT вместо градиента, тонемаппинг Uchimura в конец.

## Проверено
- `node --check renderer.js` чисто; `tsc --noEmit` чисто.
- Headless Chrome: ошибок WebGPU/компиляции шейдера нет (скриншотный тракт
  SwiftShader в этом окружении сломан сам по себе — не показатель).
- Живую картинку смотреть глазами: `npm start`.
